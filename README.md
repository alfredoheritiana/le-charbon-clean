# Le Charbon

Prototype front-end du site **Le Charbon**, construit avec React, TypeScript et Vite.

## Prérequis

- Node.js 20+
- npm

## Installation

```bash
npm install
npm run dev
```

Le serveur de développement démarre sur `http://localhost:3000`.

## Vérifications

```bash
npm run lint
npm run build
```

## Structure

- `src/` : application React, pages, composants, données et styles.
- `public/assets/aistudio/` : visuels et logos utilisés par l’interface.
- `vite.config.ts` : configuration Vite.
- `.env.example` : exemple de configuration d’environnement.

## Statut

Ce dépôt contient uniquement la source nettoyée de Le Charbon. Les archives de travail, références Pretty Patty et métadonnées AI Studio ne sont pas incluses.
